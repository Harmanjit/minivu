# minivu: French (fr) glossary

Machine translation; needs review by a native speaker. Follows Apple's macOS
French (Finder, Photos, Aperçu). Formal "vous". Sentence case for every title,
menu item and button (only the first word and proper names capitalised).
Menu commands and buttons use the infinitive ("Ouvrir…", "Placer dans la
corbeille"); help text addresses the reader with the imperative ("Choisissez",
"Faites glisser"). Progress titles use a noun ("Conversion de…", "Exportation
de « %@ »…"). Undo step names (MinivuRender "Name of an edit") use nouns
("Recadrage", "Rotation à gauche") so "Annuler %@" reads well.

## Typography

- Non-breaking space (U+00A0) before `:` `;` `?` `!` and `%`, and inside « ».
- “%@” → « %@ »; apostrophe is ’ (U+2019); ellipsis is … (U+2026).
- Number + unit separated by U+00A0: `%@ Mpx`, `%lld px`, `%lld s`, `%lld %%`, `4 Go`.
- Thousands separator in fixed text: space ("1 000 pixels").
- Shortcut glyphs (⌘ ⌥ ⇧ ⌫ ← → ↑ ↓) and keys in brackets are kept as they are.

## Left in English on purpose

minivu, file-format names (JPEG, HEIC, TIFF…), on-disk folder names
("minivu Captures", "minivu Wallpapers"), rename tokens ({name}, {#}…),
the technical detail inside "(%@)" errors, the web gallery’s "Previous" and
"Next" links (the generated pages are always in English), Apple product
names (MacBook Pro, Pro Display XDR, Liquid Retina XDR), ImageIO, App
Sandbox, Vision.
