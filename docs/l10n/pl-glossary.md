# minivu – glosariusz polski (pl)

All Polish strings are machine translations (state `needs_review`) and need a native speaker's review.

## Style

- Address: informal second person singular (Twoje, zachowasz), with "Twój/Twoje" capitalised as Apple's Polish UI does.
- Menu commands and buttons: imperative (Otwórz, Zachowaj, Pokaż w Finderze). Checkbox settings: imperfective imperative (Pokazuj ukryte pliki, Pytaj przed…). Undo/edit names: verbal nouns (Kadrowanie, Rozmycie), so "Undo %@" is written "Cofnij: %@".
- Capitalisation: sentence case. Only the first word is capitalised, except proper names (Finder, Spotlight, AirDrop).
- Quotation marks: „…”. Ellipsis: … (one character). Shortcut glyphs (⌘ ⌥ ⇧ ⌫) and key names (Return, Esc, Tab, Home, End, Page Up/Down, Delete) stay as they are. Space is "spacja".
- Plurals: one / few / many / other (other = fractions, genitive singular: "1,5 pliku").
- Error pattern: "Nie można + infinitive" (Nie można odczytać pliku.).
- Help page titles match the HelpPage titles: Pierwsze kroki, Przeglądarka, Widok obrazu, Edycja, Efekty i retusz, Narzędzia, Ustawienia, Prywatność, Skróty klawiszowe.
