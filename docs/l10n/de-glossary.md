# minivu – German (de) glossary

Machine translation, needs review by a native speaker. Terminology follows
Apple's German macOS (Finder, Fotos, Vorschau).

## Style

- Address: informal "du" (as Apple's current German UI), "Wähle …", "Möchtest du …".
- Menu commands and buttons: infinitive ("Öffnen", "In den Papierkorb legen",
  "Bild konvertieren"); progress messages: passive ("Wird gesichert …").
- Ellipsis: "…" preceded by a space in commands and progress ("Sichern unter …",
  "Wird geschätzt …"), as in German macOS.
- Quotation marks: „…“. Dash: spaced en dash " – ".
- Percent with a space: "50 %" ("%lld %%").
- Menu path in prose: „Ablage“ > „Ordner öffnen …“ (help pages: **Ablage > Ordner öffnen …**).
- Key names: Zeilenschalter (Return), Leertaste (Space), Rückschritttaste (Delete),
  Umschalttaste (Shift), Wahltaste (Option), Befehlstaste (Command), ctrl-Taste,
  Bild auf / Bild ab (Page Up/Down), Home, Ende, Esc, Tab; glyphs ⌘ ⇧ ⌥ ⌫ kept.
