# minivu 日本語 (ja) 用語集

Apple の macOS 日本語版（Finder、写真、プレビュー）の用語に合わせています。
すべて機械翻訳であり、ネイティブスピーカーによるレビューが必要です。

## 表記ルール

- 文はです・ます調、句点「。」で終わる。メニュー項目・ボタンは体言止めまたは動詞の終止形（例：開く、切り取る…、ゴミ箱に入れる）。
- 和文と英数字・書式指定子の間にスペースを入れない（例：「この Mac」ではなく「このMac」、「%lld個のファイル」）。単位記号の前のスペースは保持（「%@ px」「4 GB」）。
- 引用符は “ ”（Apple の日本語ダイアログと同じ）。メニュー・ボタン名の参照は「」、パスは「ファイル」>「フォルダを開く…」。
- 括弧・コロンは全角（（ ）、：）。範囲は「～」（1～100）。省略記号は「…」（U+2026）を保持。
- キー名はキーボードの表記どおり小文字の英語（return、esc、delete、shift、option、home、end、page up/down、tab）＋「キー」。スペースは「スペース」/「スペースバー」。記号（⌘ ⌥ ⇧ ⌫ → ←）はそのまま。
- 複数形：日本語は CLDR の `other` のみ。助数詞：ファイル・項目・フォルダ・グループ＝個、イメージ・ピクチャ・写真＝枚、ビデオ＝本、ページ＝ページ。
- ヘルプ Markdown：CommonMark の強調ルールのため、太字は 「**ファイル**」>「**保存**」 の形にする（** を括弧の内側に）。
