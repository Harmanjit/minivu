# Glossario italiano di minivu (it)

Terminologia allineata a macOS in italiano (Finder, Foto, Anteprima). Tutte le
stringhe sono traduzioni automatiche in attesa di revisione da parte di un
madrelingua.

## Stile

- Ci si rivolge all’utente con il **tu**, come fa Apple in italiano ("Vuoi salvare le modifiche…?", "Scegli…").
- Comandi di menu e pulsanti: **imperativo di seconda persona** ("Apri", "Ruota a sinistra", "Sposta nel Cestino"), non l’infinito.
- Maiuscola **solo sulla prima parola** (sentence case), come in macOS italiano: "Nuova cartella", "Mostra file nascosti". Restano maiuscoli i nomi propri e i nomi di funzioni/luoghi Apple: Finder, Cestino, Dock, Impostazioni di Sistema, Testo live.
- Titoli di avviso con "Impossibile …" ("Impossibile salvare “%@”."), domande di conferma all’infinito ("Spostare 3 file nel Cestino?", "Eliminare “%@”?").
- Puntini di sospensione con il carattere `…`; virgolette tipografiche “ ”; nessuno spazio prima di `:` `?`.
- Plurali: categorie CLDR `one`, `many`, `other` (`many` = `other`, serve per "1 milione di …"). "file" e "video" sono invariabili.
- Tasti (come nella documentazione Apple in italiano): Return = **A capo**, Shift = **Maiuscole**, Option = **Opzione**, Command = **Comando**, Control = **Ctrl**, Delete = **Elimina**, Space = **Spazio**, Home/End = **Inizio**/**Fine**, Page Up/Down = **Pagina su**/**Pagina giù**. I glifi ⌘ ⌥ ⇧ ⌫ restano invariati.

## Non tradotti

minivu, nomi di formati (JPEG, HEIC, TIFF…), "minivu Wallpapers" e "minivu
Captures" (nomi di cartelle su disco), token di ridenominazione (`{name}` …),
EXIF/IPTC/XMP, ImageIO, Lanczos, Polaroid.
