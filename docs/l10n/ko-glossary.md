# minivu Korean (ko) glossary

Style: Apple macOS Korean. Menu commands and buttons are short noun phrases
(열기, 저장, 이름 변경…, 휴지통으로 이동), no final period. Sentences are
formal polite: statements end in -습니다, instructions in -하십시오, questions
in -하겠습니까?. Particles after a placeholder use Apple's dual form:
%@을(를), %@은(는), %@이(가), %@(으)로. Counts use counters after the noun:
이미지 %lld개, 사진 %lld장, %lld페이지, 별 %lld개. Korean plurals use only
the CLDR category `other`. Ellipsis is “…”, quotes are “ ”, key glyphs
(⌘ ⇧ ⌥ ⌫ → ←) and key names (Return, Esc, Space, Page Up) stay as on the
keyboard. Units attach without a space: 24px, 12MB, 30fps, 5500K.

In help pages, a bold command that ends in punctuation (… ` / − ] *) is
followed by a space and a noun (명령은, 키를), because CommonMark does not
close `**` between punctuation and a Hangul particle.
