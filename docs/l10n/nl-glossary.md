# minivu: Dutch (nl) glossary

Style: follows Apple's Dutch macOS (Finder, Foto's, Voorvertoning).
- Informal address with "je"/"jij", as Apple uses it in Dutch.
- Menu commands and buttons use the imperative (Open, Bewaar, Druk af…, Toon info,
  Verplaats naar prullenmand). Progress titles use the infinitive with an ellipsis
  ("Kleuren tellen…"). Edit names (Undo steps) are nouns or infinitives
  ("Herstel Bijsnijden").
- Sentence case everywhere: only the first word and proper names get a capital.
- Quotation marks: single curly quotes ‘…’, as Apple uses them in Dutch. The
  apostrophe is ’ (foto’s, pagina’s).
- Ellipsis is the single character "…". Percentages are written "50%".
- Plurals: CLDR categories `one` and `other` only. Every form keeps the number.
