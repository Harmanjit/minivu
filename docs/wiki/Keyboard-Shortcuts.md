# Keyboard Shortcuts

Every command is in the menu bar, with its key beside it. The same list is in the app: **Help > Keyboard Shortcuts** (⌘/) opens a page generated from the menus, followed by the keys the grid, the viewer, the compare window, the slideshow and the tools take directly.

## How keys reach minivu

- **Menu shortcuts** (those with ⌘, ⌃ or ⌥, and F2 and ⇧F2) work from any window where the command applies; elsewhere the item is greyed out.
- **Arrows, Home, End, P and ⌥-arrows** are shown in the **Go** and **Image** menus only while the menu is open. They aren't real menu shortcuts: the grid, the viewer or a text field takes them, so an arrow in a rename field moves the insertion point instead of changing the image.
- **Single keys** such as 0–5, `` ` ``, T, F, I, / and \* belong to the grid and the viewer. While you type in a text field they type.
- **⌘⌫, ⌘↑ and ⌘↓** in a text field edit the text (delete to the start of the line, jump to the start or end) instead of reaching **Move to Trash**, **Enclosing Folder** and **Open in Viewer**. The menu items still work when clicked.

## Browser

In the thumbnail grid.

| Keys | Action |
|---|---|
| ↑ ↓ ← → | Move the selection |
| ⇧ with an arrow | Extend the selection |
| Return, or double-click | Open the image in the viewer, or the folder in the grid |
| Type a name | Select the file whose name starts with it |
| 0–5 | Rate the selection (0 clears) |
| `` ` `` | Tag or untag the selection |
| ⌥ while dropping | Copy the dropped files |
| ⌘ while dropping | Move the dropped files |

A digit or `` ` `` typed within a second of a letter continues the name, so "IMG_2" can still be typed. T types a name in the grid, as letters do in Finder; ⌘T tags from anywhere. Hover under a thumbnail's name and click a star to rate with the pointer.

## Viewer

When the image is larger than the window, the arrow keys pan it by a tenth of the view instead of changing images.

| Keys | Action |
|---|---|
| → ↓ Space | Next image |
| ← ↑ ⌫ | Previous image |
| Home, End | First, last image |
| Page Down, Page Up | Next or previous page of a PDF or multi-page TIFF, then the next or previous image |
| ⌥→ ⌥←, ⌥Page Down ⌥Page Up | Next or previous page only |
| + or =, - | Zoom in, zoom out |
| / | Actual size |
| \* | Fit to window |
| 0–5 | Rate (0 clears) |
| T or `` ` `` | Tag or untag |
| I | Keep the info overlay up |
| F | Keep the filmstrip open |
| P | Play or pause an animation |
| Return | Switch between window and full screen |
| Esc | Back to the browser |

Held down, the keys that go to the next or previous image or page, pan and zoom repeat; the others, including Home, End, Return, F and I, don't.

## Viewer mouse and trackpad

| Input | Action |
|---|---|
| Click | Fit or actual size, at the point clicked |
| Double-click | Back to the browser |
| Press and hold | Magnifier; scroll while holding to change its zoom |
| Drag | Pan |
| Pinch | Zoom about the pointer |
| Double-tap with two fingers | Fit or actual size |
| Scroll | Next or previous image, or zoom, as **Settings > Viewer > Mouse wheel** says; hold ⌘ for the other |
| Pointer to an edge | Filmstrip (top), tools (left), info and histogram (right), controls (bottom) |

On a trackpad, scrolling a zoomed-in image pans it instead of changing images. While an editing tool is open, a mouse wheel always zooms (⌘ doesn't swap it) and a trackpad pans.

## Full screen

The viewer's full screen is instant, with no new Space. The same keys work as in a window.

| Keys | Action |
|---|---|
| Return, or ⌃⌘F | Back to a window |
| Esc | Back to the browser |
| F, I, ⇧⌘H | Keep the filmstrip, the info overlay or the info panel up without the pointer |
| ⌃⌥⌘→ | Move to the next display |

The menu bar appears when the pointer reaches the top of the screen. In the browser, ⌃⌘F is the system's full screen.

## Compare

| Keys | Action |
|---|---|
| ⌘1–⌘4 | Choose a pane |
| Tab, ⇧Tab | Next or previous pane |
| ← → | Previous or next image in the chosen pane |
| 0–5 | Rate (0 clears) |

The **Image** menu's zoom commands act on the chosen pane, and **Sync Zoom** carries them to the others.

## Slideshow

| Keys | Action |
|---|---|
| Space | Pause or resume |
| → ↓ Page Down | Next slide |
| ← ↑ Page Up | Previous slide |

Menu shortcuts such as ⌘Q and ⌘, still work during a show. Move the pointer to bring up the control bar.

## Editing tools

| Keys | Action |
|---|---|
| Return | Apply the open tool |
| Esc | Cancel the open tool |
| ⌘Z, ⇧⌘Z | Text and Shapes, Clone Stamp, Healing Brush, Red-Eye Removal: undo and redo one step inside the open tool |
| ⌥-click | Clone Stamp, Healing Brush: set the source |
| [ ] | Clone Stamp, Healing Brush: smaller, larger brush |
| Arrows, with ⇧ ten times as far | Text and Shapes: nudge the selection |
| ⌘D | Text and Shapes: duplicate |
| ⌘C, ⌘X, ⌘V | Text and Shapes: copy, cut, paste objects |
| Esc | Text and Shapes: finish typing, then deselect, then cancel the tool |
| ⌫ | Text and Shapes, Red-Eye Removal: delete the selection |

With **Text and Shapes…**, a brush or the red-eye tool open, ⌫ never goes back to the previous image.

## Capture

**Tools > Capture > Selection…** covers every display. Drag a rectangle, then:

| Keys | Action |
|---|---|
| Return | Capture the rectangle |
| Esc | Cancel |
| ⌘Q | Cancel the capture and quit |

No other key reaches minivu while the overlay is up.
