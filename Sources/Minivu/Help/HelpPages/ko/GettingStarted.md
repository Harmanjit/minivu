# 시작하기

minivu는 Mac용 빠른 이미지 브라우저, 뷰어 및 편집기입니다. 폴더의 사진과
비디오를 축소판으로 보여 주고, 정확한 색상과 실제 HDR로 어떤 항목이든 전체
화면으로 열며, 저장하기 전까지는 원본을 변경하지 않고 편집합니다.

## 폴더 열기

- minivu를 처음 열면 사진 폴더가 표시됩니다. 그 이후에는 마지막으로 보고
  있던 폴더가 열립니다.
- 다른 폴더를 탐색하려면 **파일 > 폴더 열기…** 명령을 선택하십시오. minivu가
  해당 폴더를 사이드바에 추가하므로 앱을 종료한 후에도 다음 번에 한 번의
  클릭으로 열 수 있습니다.
- **파일 > 사이드바에 폴더 추가…** 명령을 사용하면 현재 폴더를 떠나지 않고
  폴더를 추가할 수 있습니다.
- Finder에서 minivu로 이미지를 열거나(Control-클릭한 다음 **다음으로 열기**),
  Dock에 있는 minivu 아이콘 위에 폴더를 놓으십시오.

> minivu는 Mac의 내장 저장 공간에 있는 폴더에서 작동합니다. 메모리 카드,
> USB 드라이브 또는 네트워크 공유에 있는 사진을 보려면 먼저 Mac의 폴더로
> 복사하십시오.

## 사진 보기

축소판을 이중 클릭하거나 선택한 다음 Return 키를 누르면
[뷰어](help:Viewer)에서 열립니다. 화살표 키와 Space 바로 폴더를 탐색하고,
Esc 키를 누르면 브라우저로 돌아갑니다. Return 키를 누르면 뷰어가 윈도우와
전체 화면 사이에서 전환됩니다. 비디오는 Space 바를 누르면 재생됩니다.

## 가장 좋은 사진 고르기

선택한 사진에 별을 지정하려면 **1**~**5**를, 별을 지우려면 **0**을
누르십시오. 보관하려는 사진에 태그를 지정하려면 백쿼트 키(**`**)를
누르십시오. 그런 다음 도구 막대의 필터 메뉴를 사용하여 해당 사진만
표시하십시오. [브라우저](help:Browser)를 참조하십시오.

여러 폴더를 한 번에 살펴보려면 **편집 > 찾기…** 명령(**⌘F**)을 선택하거나,
폴더와 모든 하위 폴더를 함께 보려면 **보기 > 평면 보기**(**⌥⌘F**)를
선택하십시오.

## 편집 및 저장

뷰어에서 **이미지** 메뉴의 도구를 선택하거나, 포인터를 화면 왼쪽 가장자리로
이동하여 모든 도구를 보십시오. **파일 > 저장** 또는 **다른 이름으로
저장…** 명령을 선택하기 전까지는 디스크의 어떤 것도 변경되지 않습니다.
[편집](help:Editing)을 참조하십시오.

## 명령 찾기

- minivu의 모든 기능은 메뉴 막대에 있습니다. 이름으로 명령을 찾으려면
  **도움말** 메뉴의 검색 필드에 입력하십시오.
- [키보드 단축키](help:KeyboardShortcuts)에는 모든 단축키가 나열되며, 항상
  메뉴와 동일하게 최신 상태로 유지됩니다.
- minivu는 인터넷에 절대 연결하지 않습니다. [개인정보 보호](help:Privacy)를
  참조하십시오.

## 언어

minivu의 메뉴와 이 도움말은 Mac의 언어로 표시됩니다. minivu에만 다른 언어를
사용하려면 **시스템 설정 > 일반 > 언어 및 지역**의 응용 프로그램에 minivu를
추가하십시오. minivu는 영어, 독일어, 프랑스어, 스페인어, 이탈리아어,
포르투갈어(브라질), 네덜란드어, 폴란드어, 일본어, 중국어(간체) 및 한국어로
제공됩니다. 번역은 기계로 이루어졌으며 아직 원어민의 검토를 거치지
않았습니다.
