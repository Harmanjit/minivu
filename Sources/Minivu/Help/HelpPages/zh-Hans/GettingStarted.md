# 入门

minivu 是一款适用于 Mac 的快速图像浏览器、查看器和编辑器。它将一个文件夹中的照片显示为缩略图，以准确的颜色和真正的 HDR 全屏幕打开其中任何一张，并且在你存储之前进行编辑不会更改原件。

## 打开文件夹

- 首次打开 minivu 时，它会显示你的“图片”文件夹。之后，它会打开你上次查看的文件夹。
- 选取 **文件 > 打开文件夹…** 以浏览其他文件夹。minivu 会将其添加到边栏，因此下次只需点按一下即可访问，即使在你退出后也是如此。
- **文件 > 将文件夹添加到边栏…** 可添加文件夹而无需离开当前文件夹。
- 在“访达”中，使用 minivu 打开图像（按住 Control 键点按，然后选取 **打开方式**），或将文件夹拖放到程序坞中的 minivu 图标上。

> minivu 支持你 Mac 内置储存上的文件夹。要查看存储卡、USB 驱动器或网络共享上的照片，请先将它们拷贝到你 Mac 上的文件夹中。

## 查看照片

连按缩略图，或选中缩略图后按 Return 键，即可在[查看器](help:Viewer)中将其打开。箭头键和空格键可在文件夹中移动，按 Esc 键可返回浏览器。按 Return 键可让查看器在窗口和全屏幕之间切换。

## 挑选最佳照片

按 **1** 到 **5** 为所选照片评定星级，或按 **0** 清除星级。按反引号键（**`**）标记你要保留的照片。然后使用工具栏中的“过滤”菜单仅显示这些照片。请参阅[浏览器](help:Browser)。

## 编辑和存储

在查看器中，从 **图像** 菜单中选取工具，或将指针移到屏幕的左边缘以查看所有工具。在你选取 **文件 > 存储** 或 **存储为…** 之前，磁盘上的内容不会有任何更改。请参阅[编辑](help:Editing)。

## 查找命令

- minivu 的所有功能都在菜单栏中。要按名称查找命令，请在 **帮助** 菜单的搜索栏中键入。
- [键盘快捷键](help:KeyboardShortcuts)列出了所有快捷键，并始终与菜单保持同步。
- minivu 从不连接互联网。请参阅[隐私](help:Privacy)。
