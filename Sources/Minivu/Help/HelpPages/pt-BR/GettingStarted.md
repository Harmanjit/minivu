# Primeiros Passos

O minivu é um navegador, visualizador e editor de imagens rápido para o seu
Mac. Ele mostra uma pasta de fotos como miniaturas, abre qualquer uma delas em
tela cheia com cores precisas e HDR de verdade, e edita sem alterar o original
até você salvar.

## Abrir uma pasta

- Na primeira vez que você abre o minivu, ele mostra a pasta Imagens. Depois
  disso, ele abre a última pasta que você estava vendo.
- Escolha **Arquivo > Abrir Pasta…** para navegar por outra pasta. O minivu a
  adiciona à barra lateral, para que ela fique a um clique de distância na
  próxima vez, mesmo depois de encerrar o app.
- **Arquivo > Adicionar Pasta à Barra Lateral…** adiciona uma pasta sem sair
  daquela em que você está.
- No Finder, abra imagens com o minivu (clique com a tecla Control
  pressionada e escolha **Abrir com**), ou solte uma pasta no ícone do minivu
  no Dock.

> O minivu funciona com pastas no armazenamento interno do seu Mac. Para ver
> fotos em um cartão de memória, um disco USB ou um compartilhamento de rede,
> primeiro copie-as para uma pasta no seu Mac.

## Ver as suas fotos

Clique duas vezes em uma miniatura, ou selecione-a e pressione Return, para
abri-la no [visualizador](help:Viewer). As teclas de seta e a barra de espaço
percorrem a pasta, e Esc leva você de volta ao navegador. Return alterna o
visualizador entre janela e tela cheia.

## Escolher as melhores

Pressione **1** a **5** para dar estrelas às fotos selecionadas, ou **0** para
removê-las. Pressione a tecla de acento grave (**`**) para sinalizar as que
você quer manter. Depois, use o menu Filtro da barra de ferramentas para
mostrar só essas. Consulte [Navegador](help:Browser).

## Editar e salvar

No visualizador, escolha uma ferramenta no menu **Imagem**, ou mova o
ponteiro até a borda esquerda da tela para ver todas. Nada no disco muda até
você escolher **Arquivo > Salvar** ou **Salvar Como…**. Consulte
[Edição](help:Editing).

## Encontrar um comando

- Tudo o que o minivu faz está na barra de menus. Para encontrar um comando
  pelo nome, digite no campo de busca do menu **Ajuda**.
- [Atalhos de Teclado](help:KeyboardShortcuts) lista todos os atalhos,
  sempre atualizados com os menus.
- O minivu nunca se conecta à internet. Consulte
  [Privacidade](help:Privacy).
